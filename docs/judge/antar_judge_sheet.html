Offline & fallback

When something fails, Antar degrades. It never invents.

Next: Security →
If the AI model is downStill answers from the registerRule router + approved templates write the answer from the rows. The model gets an 8 s cap.
If there is no internetRuns fully on-premisePoint it at a local model (Ollama, vLLM, llama.cpp): no case text leaves the machine.
If a query finds nothingSelf-heals, then says "none found"Five repair steps below. Never fills the gap with other years' data.
If an agent keeps failingCircuit breaker, 60 sThe step shows as skipped; the rest of the answer still arrives.
If there is no GPUSame search on the CPU62 ms instead of 1.7 ms, identical results.
If the server restartsThe conversation resumesEvery turn is checkpointed to disk.

Security & governance

14 layers, each enforced in code

Next: Core AI & ML →

01No free SQL

The AI only picks one of 26 approved templates. It cannot write or change a query.

02Every number checked

A number not found in the returned rows is removed. FIR IDs must match exactly.

03Vigil refuses targeting

Questions aimed at a community are refused (Article 15) and logged.

04PII masked (DPDP)

Aadhaar (Verhoeff check), phone, email, UPI, account and PAN masked before the AI sees text.

05Two-person approval

Patrols and watchlists need a second officer, a written reason and the exact payload hash.

06Tamper-evident audit

Every request and decision is on a hash chain. One edited row breaks it.

07Signed identity

HMAC-signed tokens, 8-hour expiry, revoked on sign-out.

08Rank before every agent

Each agent declares a minimum rank and refuses below it.

09Prompt-injection defence

FIR text treated as data; hidden instructions quarantined; leak canary.

10Egress allow-list

Every outbound call is checked against a list and counted.

11Hardened HTTP

Security headers, size cap, rate limit, no stack traces to users.

12An agent that argues back

Base-rate challenge before a hypothesis is confirmed. No AI model, so no hallucination.

13Places, not people

Forecasts are for places and times. No future dates leave the server.

14Locked agents & prompts

A changed prompt stops the production server from starting.

+Open web kept apart

OSINT findings stay labelled UNVERIFIED, never merged into FIRs.

Core AI & ML

Which models run, and where each one is used

Next: Tech stack →

Generative AI (language models)

01GLM-4.7-Flash

Fast chat model on Catalyst QuickML. Picks the template and fills the slots (place, crime, dates) from the question. It never writes SQL.

Used in /antar chat · 8 s cap, then the rule path

02Qwen 3.6 35B

Analysis model. Writes the final answer when several agents return results, from their rows only.

Used in multi-agent answers · Brain · case summaries

03Qwen 3.6 VL (vision)

Reads scanned documents and photos of evidence.

Used in document upload

04Local LLM option

Ollama, vLLM or llama.cpp instead of QuickML, so no case text leaves the building.

Used in offline / on-premise mode

Machine learning & statistics

05BGE-small embeddings (ONNX, int8)

Turns every FIR into a 384-number vector so similar cases can be found by meaning, not just words.

Used in Brain recall over 1 lakh FIRs · CUDA GPU in 1.7 ms

06Hybrid search + reranker

BM25 keywords and vectors merged (RRF), reranked by an MS-MARCO cross-encoder, then MMR for variety.

Used in /antarBrain · similar past cases

07Rule router + Kannada normaliser

Deterministic intent rules route most questions with no AI call; Kannada is normalised before routing.

Used in every question · English and ಕನ್ನಡ

08Poisson GLM forecast + conformal range

Expected crime per station and beat for 7 and 28 days, with a split-conformal range that holds ~80% of the time.

Used in /predict

09LightGBM challenger

Gradient-boosted model that competes with the GLM in a backtest league; it ships only if it wins.

Used in /predict · Model League (Lab)

10Anomaly detection

Robust z-score with seasonal detrending flags unusual weekly spikes, and also unusual silences.

Used in /predict alerts · patrol proposals

11Hotspot statistics

Getis-Ord Gi* hotspots, KDE heat and Uber H3 cells (~76 m) for repeat locations.

Used in /map · /trends

12Graph analytics

Louvain community detection finds gang groups; PageRank and betweenness rank key players.

Used in /network · /antarBrain

13Explainable risk score + SHAP

Linear risk score 0–100, so each factor's SHAP points are exact, not estimated.

Used in /profiles

14Bayesian Advocate (no LLM)

Prices each link against its base rate and corrects for how many pairs were scanned, then argues against weak hypotheses.

Used in hypothesis confirm gate · /antarBrain

Language models choose and explain. The numbers always come from the register, the statistics and the ML models above.
